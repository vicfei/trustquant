# Skill: 组合压力测试与重放（portfolio-stress-replay）

> 状态：官方 Skill #3（M1）。选择/构造情景 → 执行直接持仓冲击 → 对比基准 → 解释 → 重放验证。

## 适用场景

用户想知道"如果某类资产瞬间下跌 X%，我的组合会怎样"，并希望结果可复现、可审计。

## 工作流（确定性 trace 见 evals/cases/skill_stress_replay_trace.json）

1. **加载数据与权重**：`load_market_dataset` + 用户权重（缺权重时先问，不假设）。
2. **定义情景**：直接价格冲击 `{ticker: 比例}`（-0.25 = 跌 25%）。常见预设：risk_off（普跌）、single_crash（单标的腰斩）、flight_to_quality（防御资产上涨）。**不做宏观因子建模**——用户要"利率上升 100bp 的影响"这类需要因子映射的请求，如实说明不在能力范围。
3. **执行**：`stress_test_portfolio`。基准 = 数据集最后一个收盘价、单位名义；每个情景返回组合收益与逐标的贡献（贡献之和恒等于组合收益——解释时可引用该不变量）。
4. **解释**：负贡献最大的标的是主要风险源；区分"组合收益"（比例）与"pnl"（单位名义金额）。
5. **重放**：`replay_calculation`（用第 3 步返回的 calculation_id）。向用户报告"同版本同环境重放一致/不一致 + 摘要差异"，不承诺跨版本重放。

## 防护规则

- 冲击比例必须 > -1.0（-100% 以上无意义），工具会拒绝；
- 冲击未覆盖的标的默认 0 变动，解释时明说；
- 情景是假设，不是预测——禁止表述为"将会下跌"；
- 若用户给出两套权重/情景要对比，分别调用并排放结果，不改写历史清单。
